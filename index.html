Il calendario, come vuoi tu.

  1. Tocca una casella. Seleziona uno o più colori, scrivi una nota e premi “Salva giorno”.
  2. Crea i tuoi colori. Usa “Aggiungi colore”, scegli nome e tonalità e premi “Salva colori”. Le categorie valgono per tutti i mesi.
  3. Spostati nel calendario. Usa le frecce o scegli mese e anno. “Oggi” ritorna al mese corrente.
  4. Conserva una copia. “Esporta dati” salva tutti i mesi e i colori in un file JSON. “Importa dati” ripristina un backup, sostituendo i dati attuali dopo conferma.

Su iPad: apri il link GitHub Pages in Safari. Puoi aggiungerlo alla schermata Home dal menu Condividi. Il visualizzatore dell’app File potrebbe non eseguire il calendario.

Il salvataggio è locale al browser: non c’è sincronizzazione automatica fra dispositivi. La cancellazione dei dati del sito può eliminare il calendario. Un backup ti permette di recuperarlo. Il file HTML e GitHub contengono solo l’app, non le tue annotazioni.

Per pubblicarlo: carica index.html nella cartella principale del repository, poi seleziona Settings → Pages → Deploy from a branch → main → /(root) → Save.
